# Frozen documentation

Aspirational or superseded design documents. Kept for context, not as active source of truth.

Use these current docs instead:
- `docs/STATUS.md` — current implementation state
- `docs/POC_ACCEPTANCE.md` — POC pass/fail checklist
- `docs/POC_CHANGELOG.md` — dated POC progress
- `docs/FINDINGS_AND_ISSUES.md` — production gaps and backlog
- `docs/ENGINEERING.md` — engineering principles

When a frozen doc disagrees with `core/`, `worker/`, `api/`, or `docs/STATUS.md`, the active implementation and `docs/STATUS.md` win.
