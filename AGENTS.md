# Hivemind Repository Rules

The repository contains two self-contained source snapshots:

- `v1/` is the frozen POC V1 snapshot. Do not change it unless correcting the archive itself.
- `v2/` is the active development line.

Read and follow `v2/AGENTS.md` before implementation work. Apply its simulation-first requirements to paths under `v2/` (for example, `v2/core/src/vopr/` and `v2/worker/src/sim/`).
